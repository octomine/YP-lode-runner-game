# Игра Lode Runner, сделана в качестве учебного проекта в Yandex Practicum, является интеллектуальной собственностью Yandex

## Быстрый старт

### Скрипты проекта

```bash
# Установка зависимостей
yarn install

# Запуск dev сервера
yarn dev

# Деплой на gh-pages
yarn deploy
```

## Управление в игре

Управление стрелками, space - прожечь дырку перед собой
